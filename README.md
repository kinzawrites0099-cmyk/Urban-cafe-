# Urban Cafe

A premium cafe & restaurant website built with React, TypeScript, Tailwind CSS, and Framer Motion.

## Features

- Responsive design for all devices
- Animated UI with Framer Motion
- Interactive menu with category filtering
- Table reservation form (stores in localStorage)
- Google Maps integration
- SEO optimized

## Live Demo

[View Live Site](https://your-username.github.io/urban-cafe/)

## Tech Stack

- React 19
- TypeScript
- Tailwind CSS v3
- Framer Motion
- Lucide React Icons
- Vite

## Setup & Run

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Deploy to GitHub Pages
npm run deploy
```

## GitHub Pages Deployment

1. Update `vite.config.ts` with your repo name
2. Run `npm run deploy`
3. Enable GitHub Pages in repo settings
